💡 Evaluation & Ground Truth Alignment

When you click Save Ground Truth, the application saves both annotations.json and ground_truth_bounding_boxes.json into the image folder. The bounding box format is exact pixel coordinates [x1, y1, x2, y2], matching the Grounding DINO model detection format so you can directly calculate Precision and Recall with IoU thresholds!
